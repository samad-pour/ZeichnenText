# ZeichnenText

Ein Visual-Studio-Projekt zur Einführung in das Zeichnen und Darstellen von Text innerhalb einer grafischen Benutzeroberfläche.

## Beschreibung

Das Projekt **ZeichnenText** beschäftigt sich mit den Grundlagen der grafischen Textdarstellung. Im Mittelpunkt stehen das Zeichnen von Texten, deren Positionierung und Formatierung sowie die Verwendung grafischer Zeichenfunktionen innerhalb einer Anwendung.

## Funktionen

- Zeichnen und Darstellen von Texten
- Positionierung von Text innerhalb einer Zeichenfläche
- Verwendung unterschiedlicher Schriftarten und Schriftgrössen
- Anpassung von Textfarben und Formatierungen
- Grundlagen der zweidimensionalen Textdarstellung

## Technologien

- Microsoft Visual Studio
- .NET
- Visual-Studio-Projektmappe (.sln)

## Installation und Ausführung

1. Repository klonen:

   ```bash
   git clone https://github.com/samad-pour/ZeichnenText.git
   ```

2. Die Datei `ZeichnenText.sln` in Visual Studio öffnen.
3. Das Projekt erstellen.
4. Die Anwendung mit `F5` starten.
